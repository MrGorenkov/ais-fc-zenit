Автоматизированная информационная система для управления данными футбольного клуба «Зенит». Курсовой проект по дисциплине «Базы данных» (МГТУ им. Н. Э. Баумана, ИУ-5).

## Что умеет

- **Управление составом**: учёт игроков, тренеров, штаба клуба и их персональных данных
- **Календарь матчей**: расписание игр, результаты, статистика игроков по матчам
- **Достижения**: трофеи клуба, индивидуальные рекорды игроков
- **Финансы**: контракты, зарплаты, трансферы
- **Аналитика**: статистические запросы и выборки для администрации клуба

## Стек

- **Клиент** — C++ 17, Qt 6 (Widgets, SQL модуль)
- **Сборка** — CMake
- **БД** — PostgreSQL 14, PL/pgSQL для хранимых процедур и триггеров

## Структура

```
ais-fc-zenit/
├── AIS_FC_ZENIT.sql       # схема БД, заполнение, процедуры, триггеры
├── main.cpp               # точка входа Qt-приложения

├── РПЗ.pdf                # расчётно-пояснительная записка к курсовой
```

## Сборка и запуск

```bash
# 1. Создать БД и накатить схему
createdb fc_zenit
psql -d fc_zenit -f AIS_FC_ZENIT.sql

# 2. Собрать Qt-клиент
mkdir build && cd build
cmake ..
cmake --build .

# 3. Запустить (в окружении должны быть переменные подключения к PostgreSQL)
./ais-fc-zenit
```
