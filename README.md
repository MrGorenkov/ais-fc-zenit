# АИС "ФК Зенит" ⚽

Автоматизированная информационная система для управления данными футбольного клуба Зенит.

Курсовой проект по дисциплине "Базы данных"  
МГТУ им. Н.Э. Баумана, ИУ5-43Б, 2024 г.

## Описание

Система для автоматизации учета достижений игроков и результатов ФК Зенит. Предназначена для администрации клуба и болельщиков.

## Технологии

- PostgreSQL
- Python 3
- PyQt

## Установка

```bash
# Клонируй репозиторий
git clone https://github.com/yourusername/fc-zenit-ais.git
cd fc-zenit-ais

# Установи зависимости
pip install -r requirements.txt

# Создай БД
createdb fc_zenit
psql -d fc_zenit -f database/schema.sql

# Настрой config.py с данными БД

# Запусти
python main.py
